# DSA Programs in C

A collection of beginner-friendly **Data Structures and Algorithms (DSA)** programs written in C.

## Programs

| No. | Program | File |
| --- | --- | --- |
| 1 | Linear Search | [linear_search.c](linear_search.c) |
| 2 | Stack Operations Using an Array | [stack_operations.c](stack_operations.c) |
| 3 | Linear Queue Operations Using an Array | [queue_operations.c](queue_operations.c) |
| 4 | Circular Queue Operations Using an Array | [circular_queue.c](circular_queue.c) |
| 5 | Singly Linked List Operations | [singly_linked_list.c](singly_linked_list.c) |

## Concepts Covered

- Arrays and searching
- Stack: push, pop, and display
- Linear queue: enqueue and dequeue
- Circular queue and modulo-based indexing
- Singly linked lists, pointers, and dynamic memory allocation

## Compile and Run

With GCC installed, compile any program from a terminal:

```bash
gcc linear_search.c -o linear_search
./linear_search
```

Replace the filename and output name to run another program. On Windows, run the generated executable as `linear_search.exe`.

These programs are intended for learning and practice. Each source file contains a standalone `main` function and should be compiled separately.
