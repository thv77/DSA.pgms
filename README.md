## Compile and Run

Each C file is a standalone program and should be compiled separately with GCC:

```bash
gcc linear_search.c -o linear_search
./linear_search
```

Replace `linear_search.c` and `linear_search` with the desired source and executable names. On Windows, run the generated `.exe` file.

These programs are for learning and practice. Check the comments and input format in each source file before running.
